This is a machine learning project designed to estimate yield curves of different sovereign nations using the attention architecture,
first published in Vaswani et al. 2017. The layout of this particular model is based on, and built from, Richman and Scognamiglio 2024,
who published their article with the International Actuarial Association.

A link is available here;
"https://www.cambridge.org/core/journals/astin-bulletin-journal-of-the-iaa/article/multiple-yield-curve-modeling-and-forecasting-using-deep-learning/757EF58E6ADFE54C25B813E12D21232C"

Data is pulled from the European Insurance and Occupational Pensions Authority (EIOPA), by API request.
